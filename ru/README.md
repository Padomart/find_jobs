# ru — вакансии Go/Backend на российском рынке

Junior/Middle, удалёнка (в том числе «по России»). Источники включаются и настраиваются в
`ru/config_ru.yaml`.

| Источник | Что нужно |
|---|---|
| `habr` | ничего (официальный RSS Хабр Карьеры) |
| `superjob` | `SUPERJOB_KEY` (api.superjob.ru, «Регистрация приложения») |
| `trudvsem` | ничего (открытое API «Работа России») |
| `telegram` | ничего (публичные превью `t.me/s/<канал>`, список каналов в конфиге) |
| `yandex`, `vk`, `mts` | ничего (публичные данные карьерных сайтов) |

## Примеры (из корня папки)

```bash
python3 ru/find_ru_jobs.py
```

```bash
python3 ru/find_ru_jobs.py --sources habr,telegram --days 14
```

```bash
python3 ru/find_ru_jobs.py --check
```

```bash
python3 ru/find_ru_jobs.py --push-jobsync --dry-run
```

Полный список флагов: `python3 ru/find_ru_jobs.py --help`.

## Файлы

| Путь | Что |
|---|---|
| `ru/config_ru.yaml` | запросы, фильтры (`max_years_required: 5`), источники, AI, JobSync |
| `resume.txt` (в корне) | краткое резюме для `--ai`, общее с boards (путь — `ai.resume_file` в конфиге, относительно корня) |
| `ru/out/jobs_ru.json`, `ru/out/report_ru.md` | результаты последнего запуска |
| `state/seen_ru.json` | уже виденные вакансии и кэш AI-оценок |
| `state/jobsync_ledger.json` | общий с boards учёт лимита JobSync |

Отправка в JobSync идёт через общий клиент `common/jobsync_push.py`: батчи по 10, проверка
`find_job` перед добавлением (если `check_duplicates: true`), не больше `budget_per_hour` вызовов в час.

## Что в отчёте

- Оценка (эвристика): Go как **основной** язык даёт +1,5…+2,5; если Go стоит рядом с другими языками
  («Oracle developer (+Delphi+Vue+Go)», «Java developer» с Go в тексте) — −1 и пометка «Go не основной язык».
- Senior/Lead/ведущий/старший в заголовке отсекаются всегда, в том числе «Middle+/Senior».
- Ограничения для работы не из России: «только РФ», «гражданство РФ», «резидент РФ», «оформление по ТК РФ»,
  «допуск/гостайна» — показываются строкой ⚠️ под вакансией (⛔ — жёсткие), оценку не меняют и уходят в
  описание JobSync. У Хабра RSS отдаёт только короткий текст, поэтому там видно не всё — проверяйте по ссылке.
- Блок «Источники, которые дали 0, и почему»: пропущен (нет ключа / 403), ничего не вернул, все отсеяны
  фильтрами (топ причин) или все уже были в прошлых запусках.

## Что требует вашего решения

- **SuperJob** — зарегистрировать приложение на api.superjob.ru и задать `SUPERJOB_KEY`.
- **DeepSeek** — для `--ai` создать `resume.txt` в корне (5–15 строк) и задать `DEEPSEEK_API_KEY`.
  Платные вызовы — только по прошедшим фильтры вакансиям, не больше `ai.max_calls`, оценки кэшируются
  в `state/seen_ru.json`.
- **JobSync** — `JOBSYNC_URL`, `JOBSYNC_TOKEN`. С проверкой дублей одна вакансия стоит 2 вызова лимита
  (`find_job` + место в `add_jobs_batch`), т.е. ~25 вакансий в час при `budget_per_hour: 50`;
  `--no-dup-check` экономит лимит (повтор не создаёт дублей благодаря `upsert`).

AI-оценка и отправка в JobSync проверены на локальном фейковом сервере (формат запросов, батчи,
учёт лимита), с настоящими DeepSeek/JobSync — нет.
